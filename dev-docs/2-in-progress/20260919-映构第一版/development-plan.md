# 映构第一版

基于融光 main 开发综合视频创作平台，先交付「项目 → 角色设定 → 图片生成 → 确认形象」闭环。

- 新增创作首页和项目角色工作台，接入现有认证、项目、资产、图片生成 API。
- 角色设定沿用资产 properties，生成任务以 category 绑定角色；后端增加用户范围内的项目与分类筛选，无数据库迁移。
- 生成结果确认后写入子资产及角色封面，可在原分镜工作台引用。
- 品牌改为映构，保留 MIT 与上游归属。
- 完成构建、功能测试及云端 Docker Compose 部署配置；部署等待用户提供服务器连接信息和模型配置。

第一阶段不新增视频生成协议，继续保留上游视频功能。不会用模拟结果替代真实生成。
